# Glossary

Use these words in code, comments and docs, each for one thing. The terms only one layout uses are in its `README.md`. Persisted field names can't be renamed without a major release, so where the sidebar's label differs, the table gives both.

| Term                | Meaning                                                                                                        | In code                                                          | Sidebar label          |
| ------------------- | -------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------- | ---------------------- |
| Calendar date       | A day, with no time of day and no time zone                                                                    | `PlainDate`                                                      | —                      |
| Instant             | A moment in time; used only to format a date                                                                   | `Date`, built only by `utcDate`                                  | —                      |
| Week start          | The weekday a week begins on: the setting (maybe `auto`) or the resolved day                                   | `WeekStartSetting`, `WeekStart`, `resolveWeekStart`              | Week starts on         |
| Week                | Seven days of the year from the week start, reaching into the previous or next year                            | `Week` (`weeksOfYear`)                                           | —                      |
| In month / in year  | Whether a drawn day belongs to the month or year its grid or page is about; the others are gray                | `CalendarDay.inMonth`, `WeekDay.inYear`                          | —                      |
| Calendar model      | What every layout's pages are planned from: resolved week start, the year's months, month names                | `CalendarModel` (`calendarModel`)                                | —                      |
| Page plan           | What each sheet of a layout holds, before it is drawn                                                          | `planWeekPages`, `WeekPages`, … (`layouts/<layout-id>/pages.ts`) | —                      |
| Layout              | One way of spreading a year over sheets                                                                        | `LayoutId`, `LayoutSpec`, `LayoutView`                           | Layout                 |
| Workspace           | The projects kept in this browser, and the open one                                                            | `Workspace`, `openProject`, `projectList`                        | —                      |
| Project             | One calendar being made: its id, name, layout and options, as a file holds it                                  | `Project`, `openProject`                                         | Project                |
| Project id          | A project's identity, a UUID, kept whatever its name; a file carries it, so opening it finds the project again | `ProjectId`, `newProjectId`, `isProjectId`                       | —                      |
| Project name        | What the user calls a project: optional, kept as typed, never printed                                          | `Project.name`                                                   | Name                   |
| Serialized project  | One project as JSON, a file's or a stored project's                                                            | `serializeProject`, `parseProjectDocument`, `PROJECT_FORMAT`     | project file           |
| Preferences         | How the app looks and behaves for the viewer, apart from any calendar                                          | `Preferences`, `usePreferences`                                  | —                      |
| Zoom                | How large the preview draws the pages on screen: a level, or a fit following the preview's size                | `PreviewZoom`, `zoomScale`, `ZoomBar`                            | Zoom                   |
| Options             | A project's values, of its layout's set; a component taking them calls its prop `options`                      | `LayoutOptions[id]`, `AnyLayoutOptions`                          | (layout) settings      |
| Option group        | The options of one drawn element, edited and reset by one sidebar section                                      | `header`, `miniMonth`, `content`, `footer`, `optionsGroup`       | (section) settings     |
| Sheet / page        | One printed piece of paper                                                                                     | `Page`                                                           | page                   |
| Page setup          | Paper size, orientation, margins, equal margins, mirrored margins, spine, booklet                              | `PageSetup`                                                      | Page                   |
| Booklet             | Pages printed two per side of a sheet twice their size, ordered to read in order once folded                   | `PageSetup.booklet`, `bookletSides`, `Booklet`                   | Print as a booklet     |
| Spine               | The first page's bound edge; with mirrored margins, even pages swap the margins either side                    | `Spine`, `PageSetup.spine`                                       | Spine                  |
| Content box         | The area inside the margins                                                                                    | `contentBox`                                                     | —                      |
| Heading, subheading | A page's title lines                                                                                           | `CalendarHeader`                                                 | Title                  |
| Month grid          | A month as rows of weeks under the weekday names                                                               | `MonthGridOptions`, `MonthGrid`, `MiniMonth`                     | Content                |
| Event               | A named day from the user's list, on one date or every year (`0000`)                                           | `CalendarEvent`, `CommonOptions.events`, `eventNames`            | Events                 |
| Mini month          | A small month drawn for context, marking a day or framing a week                                               | `MiniMonth`, `miniMonth` (`MiniMonthStyle`)                      | Mini calendar          |
| Schedule            | One row per hour, from the first hour to the last                                                              | `HourSchedule`, `content.fill` = `hours`                         | Hours, Hourly schedule |
| Weekend highlight   | The weekend color on days, or on whole columns                                                                 | `WeekendHighlight`, `highlightWeekends`, `highlightWeekendDays`  | Highlight weekends     |
| Normalize           | Apply a layout's cross-field rules to stored values                                                            | `LayoutSpec.normalize`                                           | —                      |
